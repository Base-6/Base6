Meet the word: Initiate

To initiate means to make the first move and get something going. When you initiate, you are the one who starts it: the first message, the first step, the first push. Everything else follows from that.

Here is the useful secret. Starting is nearly always the hardest part. Once something is moving, it tends to keep moving. So the whole trick is often just the first push.

Word roots: initiate comes from the Latin initium, meaning a beginning. It shares that root with initial (the first letter) and initiation (a start or a joining).

Say it: in-ish-ee-ate

Build the Domino Run

Each run has gaps in the chain. Fill them from the tray: tap a domino in the tray, then tap a dashed gap to drop it in. When your chain looks joined up, initiate the run and watch it go. If it stops short, you have found a gap. Fill it and set it off again.

Every run built and set off. You did not just watch these, you made them. That is the difference between a run that happens and a run you initiate.
